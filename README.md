# Fraud-Detection
**Fraud Detection – Bank Transaction Fraud Analysis & Prediction**
*Main Contributor / Machine Learning Project*

• Built a machine learning model to detect fraudulent bank transactions using the synthetic BankSim dataset, focusing on the problem of highly imbalanced fraud data.
• Took the main role in data preprocessing, feature engineering and model development, including categorical encoding, frequency encoding, risk-based features and handling class imbalance with SMOTE/class weighting.
• Trained and compared multiple classification models, including Logistic Regression, Decision Tree, Random Forest and XGBoost, then optimized XGBoost using hyperparameter tuning and decision-threshold adjustment.
• Improved model practicality by reducing false positives while maintaining strong fraud detection performance, achieving 0.7620 Precision, 0.7403 Recall, 0.7510 F1-score and 0.9964 ROC-AUC.
